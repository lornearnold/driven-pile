# driven-pile

Long-term capacity of driven piles from the pile-driving log.

`driven-pile` implements a method in which each logged foot of driving characterizes friction angle of the soil at the pile toe.
The pore pressure generated by hammer blows reduce the soil's resustance during driving.
The end-of-drive capacity representes the resistance of the soil with elevated porewater pressure. 
The long-term capacity representes the resistance of the soil after all porewater pressure has dissipated.
Uncertainty in driving-formula capacity, data smoothing, friction angle estimate, cyclic resistance ratio, and soil properties outside the logged elevations is modeled with an optional Monte Carloo simulation.

**Status:** pre-release.

## Use

```python
import driven_pile as dp

pile = dp.Pile.octagonal(width_in=24, length_ft=150)
hammer = dp.Hammer(ram_weight=20.0)  # kips
log = dp.DriveLog.from_csv(
    "pile_B-25.5.csv",
    pile,
    hammer,
    depth="depth_ft",
    bpm="bpm",
    bpf="bpf",
    tip_elevation=-141.0,
    pile_id="B-25.5",
)
soil = dp.SoilProfile(
    mudline=-30.0,  # ft
    elevation=[-30, -80, -150],
    fines=[10, 35, 15],
)  # ft, percent

result = dp.analyze(log, soil)
print(result.drive.ltc, result.drive.ltc_shaft, result.drive.toe_eod)

result = dp.analyze(log, soil, run_mc=True)
print(result.mc.quantiles([0.05, 0.5, 0.95]))
```

The deterministic result uses the lowest admissible friction angle for theunlogged top segment; `result.top_band` holds the whole admissible band.Fines content is given as a table of elevation versus percent fines, or asingle value for a uniform profile.

Units are US customary throughout (feet, kips, kips per square foot), matching the construction records the method was developed on.
